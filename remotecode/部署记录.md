# 思源笔记部署教程

## 〇、创建工作目录

```bash
mkdir -p ~/cloudnote
```

```bash
cd ~/cloudnote
```

```bash
pwd
```

应输出 `/home/ubuntu/cloudnote`。

---

## 一、安装基础工具

```bash
sudo apt install -y sqlite3
```

---

## 二、安装 Docker

### 2.1 上传脚本

将本地 `01-install-docker.sh` 的内容复制到服务器：

```bash
nano ~/cloudnote/01-install-docker.sh
```

粘贴内容，`Ctrl+O` 保存，`Ctrl+X` 退出。

### 2.2 执行安装

```bash
bash ~/cloudnote/01-install-docker.sh
```

### 2.3 验证

```bash
docker --version
```

看到 `Docker version xx.xx.x` 即完成。

---

## 三、配置镜像加速（国内必需）

Docker 默认从国外拉取镜像，国内直连会超时。此步骤为 Docker 全局配置，对所有镜像拉取生效。

### 3.1 上传脚本

将本地 `01b-docker-mirror.sh` 的内容复制到服务器：

```bash
nano ~/cloudnote/01b-docker-mirror.sh
```

粘贴内容，`Ctrl+O` 保存，`Ctrl+X` 退出。

### 3.2 执行配置

```bash
bash ~/cloudnote/01b-docker-mirror.sh
```

---

## 四、部署思源笔记

### 4.1 修改授权码（可选）

部署脚本中默认授权码为 `cloudnote`。如需修改，在本地打开 `02-deploy-siyuan.sh`，找到第 25 行的 `--accessAuthCode=cloudnote`，改为自己的密码。

### 4.2 创建部署脚本

将本地 `02-deploy-siyuan.sh` 的内容复制到服务器：

```bash
nano ~/cloudnote/02-deploy-siyuan.sh
```

粘贴内容，`Ctrl+O` 保存，`Ctrl+X` 退出。

### 4.3 执行部署

```bash
bash ~/cloudnote/02-deploy-siyuan.sh
```

等待 3-5 分钟，最后看到访问地址即完成。

### 4.4 打开笔记系统

浏览器输入 `http://你的服务器IP`，输入授权码 `cloudnote` 即可使用。

---

## 五、修改授权码

两处文件需同时修改，否则重启会互相覆盖：

**第一步**，编辑 `docker-compose.yml`：

```bash
nano ~/cloudnote/docker-compose.yml
```

找到 `--accessAuthCode=cloudnote`，改成新密码，保存退出。

**第二步**，编辑思源配置文件：

```bash
sudo nano ~/cloudnote/siyuan-data/conf/conf.json
```

找到 `"accessAuthCode"` 字段，改成相同的新密码，保存退出。

**第三步**，安全重启容器：

```bash
cd ~/cloudnote && sudo docker compose stop siyuan && sudo docker compose up -d
```

> 不要用 `--force-recreate`，可能导致未保存的笔记丢失。

## 六、常用操作

### 6.1 笔记数据存哪里

所有笔记和附件保存在：

```
~/cloudnote/siyuan-data/
├── temp/siyuan.db          ← 笔记数据库（核心）
└── data/assets/            ← 附件/图片
```

备份这个目录即可保护所有数据。

### 6.2 恢复内置帮助文档

如果不小心删除了思源自带的"从这里开始"帮助文档：

1. 浏览器打开笔记系统
2. 点击左上角头像 → **设置**
3. 进入 **关于** 页面
4. 点击 **重新创建用户指南**
